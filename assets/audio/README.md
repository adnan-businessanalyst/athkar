# ملف الأذان

ضع ملف الأذان هنا باسم:

```
adhan.mp3
```

أو استورد أي ملف صوتي من **الإعدادات → ملف الأذان** داخل التطبيق.

## أين تجد ملفاً قانونياً

استخدم تسجيلاً تملك حق استخدامه، أو ملفاً عاماً / برخصة واضحة، مثلاً:

- [ويكيميديا كومنز — أذان](https://commons.wikimedia.org/wiki/Category:Audio_files_of_Adhan)
- تسجيل أذان من مسجدك بعد أخذ الإذن

الصيغ المدعومة: `mp3`, `wav`, `m4a`, `ogg`.

بعد وضع `adhan.mp3` في هذا المجلد أعد تشغيل التطبيق. إن لم يوجد الملف، تُعرض إشعارات الصلاة بصوت النظام حتى تستورد تسجيلاً.
